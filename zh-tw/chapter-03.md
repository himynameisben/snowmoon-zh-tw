# 第三章

<div class="dateline chapter-open"><hr class="rule"/><span class="txt"><span class="place">維瑞迪亞，梅爾丹</span><span class="sep">·</span><span class="date">3724 年雪月 8 日</span></span></div>

格拉迪亞斯沿著人行道往前走。馬路兩側是一間接一間的小店，從花、衣服到電子設備，什麼都賣。他穿過一條街。

街的另一頭，路面向下傾斜，順勢接進一條隧道。隧道裡的燈光剛好亮到能舒服地看東西、讀字，再多就沒有了。

格拉迪亞斯走到一個 Y 字形的岔路口。牆上貼著一張海報，四個角各用一塊膠帶固定。他在海報正前方停下來看。

<div class="device-view wide-device-view device-view-left" style="background-color:#633; font-size:93.75%; color:#fee; --dv-ink:#fee;"><b>從安逸的維瑞迪亞，到強大的維瑞迪亞</b>
<hr style="background:#fee; margin-top: 10px"/>
<p>學校告訴你，維瑞迪亞是個美麗的國家。你每天都看得到：樹木、山巒，還有那些房屋和建築，個個都想方設法，只求把土地稅再壓低幾個基點。</p>
<p>但你心裡知道，這裡出了問題。維瑞迪亞上一次上太空是什麼時候？二十年前。維瑞迪亞最高的建築是什麼時候蓋的？四十年前。為什麼？因為你們所有的制度——掌舵制度、圖譜募資機制，乃至整個<em>文化</em>——都是為了讓人在當下過得舒適快樂而打造的，絲毫不顧明天。</p>
<p>反觀北極帝國。住宅、交通、工業蓋得最快的地方在哪裡？在北極帝國。那些努力讓人活得更久的科學家呢？都在北極帝國。</p>
<p>維瑞迪亞對這些科學家說了什麼？活得更久沒那麼重要。死亡與誕生沒什麼不好，那是生命的自然循環。沒錯，他們就是這麼相信的。「生命的自然循環」，就是他們能拿出來最好的道德——照這套扭曲的邏輯，任何不公不義都可以是自然的，就像老虎吃兔子。</p>
<p>維瑞迪亞眼中的自然，像一株植物。美麗，卻永遠長不過自己的高度。我們眼中的自然，像一頭獅子。如果這樣的願景打動了你，如果你希望維瑞迪亞更強大、伸手摘星，目標不只是一點一滴地改善公共衛生，而是追求永生，那麼維瑞迪亞需要你們——下一代的領導者——來<em>掌握大局</em>。別理會群眾。建造未來。加入我們，我們一起建造。</p>
<p>謹致問候，</p>
<p>艾費里昂勳爵</p>
<p>北極帝國駐維瑞迪亞領事</p></div>

「耶，又是北極的宣傳。」格拉迪亞斯心想。當然，北極帝國和其他人一樣有言論自由，但他很好奇，是哪種維瑞迪亞人會願意破壞公共環境，在維瑞迪亞的隧道裡貼出他們的文宣列印稿。他開始盤算要怎麼把海報撕下來。

忽然，有人拍了拍格拉迪亞斯的肩膀。

格拉迪亞斯轉過頭。

------------------------------------------------------------------------

「喔，是你啊，莫夫？」

「不是，我是北極皇帝。專程來吸走你的靈魂，不是比喻喔。」

「好啦好啦……等等，穿著隱私袍往大梅港走的人大概有一百個，我只是其中之一，你怎麼知道我在哪？」

「你一年前把我加進信任名單，之後就沒刪掉，所以我們的本地 AI 有權限開啟位置分享。你的 AI 知道我們說好要先碰面，之後你去見那位神祕紳士時我會暗中跟著你，所以今天就對我開放了位置分享。」

「啊——懂了……什麼什麼情境親密度，還是最近流行的什麼新詞。」

「對啊，搞不好連兩方混淆電路的功能都用不到。」

「那你最近在想些什麼？」

「嗯，我今年被分到網路媒體的其中一條開放性規準。我們守律者小組一直在討論要不要調高 API 限制的稅。一個月前我跟一場公民會議談過這個題目，他們對現在的狀況非常不滿。」

「為什麼現在會變成這麼大的問題？」

「藍鯨一個月前宣布要砍掉 API，只讓通過驗證的硬體連上平台。他們說是為了擋自動化的垃圾訊息，但會議上幾乎每個人都覺得，他們只是想封鎖替代介面，好更能控制大家的注意力、榨出更多錢。」

「我們知道他們具體在做哪些事嗎？有哪些演算法是公開的嗎？」

「沒有，他們的演算法完全不透明，這部分他們已經在繳最高稅級了。」

「這樣啊……」

「所以啊，很多守律者覺得應該對這種行為多課一點稅。這樣要嘛他們收手，要嘛，呃，他們繼續做，網路變得更爛，但政府能收到夠多錢，讓大家都享有更好的醫療。問題是，藍鯨一直在強力反對。有個守律者不夠注意隱私，最近她和她的立場都被人查出來，事情傳開了，才過幾天她先生就丟了工作。不知道兩件事有沒有關係，但，嗯，這就是為什麼我們得靠這一大堆密碼學網路隨機選出守律者、匿名討論和投票，還得穿隱私袍，才能讓這整套稅制運作。」

一提到藍鯨，格拉迪亞斯就想起年輕的時候。那時他學寫程式，是替另一個大型社群平台銀聊寫第三方用戶端。他知道，這之所以做得到，全是因為銀聊的 API 是開放的，平台也允許開發者做第三方用戶端、允許使用者匯出並搬移自己的資料——這些決定無疑是為了降低他們在軟硬體開放性規準上的稅率，至少在那些斤斤計較的財務人員面前，是拿這個當理由。正是那段經驗，讓格拉迪亞斯想要有所回饋，自己也投入掌舵的工作。

「對了，說到隱私，你那位信譽 200 的匿名朋友，你打算怎麼辦？」

「嗯，他跟我說，他覺得整個掌舵機制從根本上就壞了。我想先聽聽他怎麼說。就算是瘋子，通常至少也有一成是對的，而且對得很有意思。順便希望能查出一點線索，看他是怎麼找到我的？」

「那……要是這是陷阱，想挖更多能拿來要脅你的資料呢？」

「嗯，如果他真的想害我，大可直接把我的身分和任務送進網路，讓我今年整年都跟哨兵資格無緣。不過反正，搞清楚這種事，本來就是你來這裡的目的。」

莫夫接著敞開隱私袍，從內袋掏出一個大包裹。

「來，談其他正事之前，先換上一件新的隱私袍。以防你那件沾了什麼髒東西，讓人能追蹤你。北極人把監控裝置走私進來的本事進步得很快，比我們偵測的本事進步得還快。我們的被害妄想得再升級一下。」

「要是已經嚴重到這種程度，我們根本就不該見面才對吧。」

「少來了，格拉德，你不只是快要加入我們、成為哨兵的人，你是我朋友。我喜歡跟你見面——趁現在還見得到的時候。」

------------------------------------------------------------------------

隧道往上爬升，戶外的光線再次照進格拉迪亞斯眼裡。道路兩側都有樹木遮蔭。

他經過兩個站在飲水台旁聊天的孩子。他聽出其中一個在說最近和家人去北林玩的事，另一個則說他喜歡他們的旋翼球隊。

他走到聽不見他們說話之後沒多久，手錶就震動了。

他看了一眼。

賽菈傳來幾張自由城的照片。第一張是市中心。第二張是一座大公園，從入口閘門前拍的。左邊有一張寫了些字的告示。他把手錶湊近眼前，看出那是一張價目表。

格拉迪亞斯按了一個鍵，回了一個愛心符號。

他把注意力從手錶螢幕拉回街上，這才發現自己已經走進梅爾丹比較都會、也比較商業化的一區。

右邊是一排辦公大樓。遠一點的那幾棟是明亮的玻璃與鋼構建築，閃閃發光，不過隔著這段距離，只能從樹叢後面看到一部分。近處的幾棟正在施工，全都圍著高大的圍籬，把工地擋在大眾的視線之外。

第一道圍籬上有一張海報，提醒維瑞迪亞人善待家人和社區。

第二道圍籬上又是一則海卓菲廣告。廣告左邊是經典的海卓菲水瓶，滿是黃綠配色。

右邊則是這段文字：

> 氫氧化氫是：
>
> - 有毒汙水中常見的物質
> - 大量攝取會致命
> - 經常被用在受刑求的囚犯身上
> - 以固態長時間握在手中會造成皮膚損傷
>
> 但你知道嗎？今天你就能買到專屬於你的一整瓶新鮮可飲用的氫氧化氫！
>
> 海卓菲，立即購買。

格拉迪亞斯又笑了。這個工程已經施工很久了，他很感謝這兩張海報替工地遮醜。比起起重機和蓋到一半的水泥建築，他寧可看海卓菲的廣告，*或*維瑞迪亞的美德海報，哪個都好得多。

接著他把注意力轉向左邊那道長長的、像城牆一樣的牆，灰色和紫色交錯。

牆前有兩排樹，中間夾著一條人行道。

樹後的牆上掛著一張大海報：

「快來了解大梅港為你的社區做了哪些事！」

文字的背景是一群撿垃圾的機器人，畫成適合小朋友的卡通風格。右下角有一個二維條碼。格拉迪亞斯出於好奇掃了一下。

格拉迪亞斯看見兩個人坐在長椅上，各自喝著一杯茶，看著那面看板，其中一人腿上放著手持裝置。

「你進去過嗎？」第一個男人問。

「沒有，一直沒拿到簽證。」第二個人回答。

「那地方很有意思，裡面跟維瑞迪亞其他地方完全不一樣，幾乎就像國中之國。」

格拉迪亞斯停下腳步，面向看板，以免引人起疑。偷聽別人說話有點失禮，但了解民意是他身為未來哨兵的職責之一。公民諮詢會議是有幫助，但永遠比不上一段真實的對話——說話的人並不知道有人在聽。

第二個男人低頭看著兩人共用的手持裝置。「哇，你看他們繳的稅。」

「他們繳多少稅？」格拉迪亞斯問翡翠。他無聲地低語，只有頸帶讀得出他在說什麼。

翡翠立刻回答。

「營業稅平均 5.2%，為全市平均的一半。土地稅合計 1.48%，略高於全市平均。圖譜募資，尤其是平方募資的收入，約可回收其中一半。」

格拉迪亞斯把注意力轉回那段對話。

「我搞不懂。這些人只是安安靜靜待在角落，自己過自己的。我從沒去過那裡，他們也從沒煩過我。他們甚至還做了這麼多環境、教育、醫療、博物館的事。他們連專心做自己真正擅長的科學都不行，還得做這一堆討好民眾的事來壓低稅金、從平方募資拿回一點錢，而那些事他們根本也不擅長。結果做了這麼多之後呢？還是一堆人討厭他們，假裝他們的牆很醜，就為了把他們的土地稅推高。我們自己就是自己最大的敵人，幹嘛還那麼擔心北極人？」

「至少在這裡，我們能對他們做的頂多就這樣。要是在德文維爾或英格沃爾，大梅港還得拚命才不會被整個關掉。」

格拉迪亞斯已經將近十年沒進過大梅港，這讓他更好奇，想再進去看看。他繼續往前走。

------------------------------------------------------------------------

格拉迪亞斯把手錶靠近入口閘門上的綠色圓圈，等了大約一拍。

「證明已驗證，歡迎。」機器回答，語氣機械，卻帶著幾分嘉許。

他走過閘門。

他一眼就看出，為什麼長椅上那兩個人會說大梅港和維瑞迪亞其他地方那麼不同。

大梅港裡的建築比外面整齊劃一得多，全是類似的圓形和方形，白、灰、紫三色交錯，高度大約五到十公尺。樹木只有少數幾種，在人行道上等距仔細種好。除了各有不同的店名和四分之一公尺寬的不同標誌之外，商店和餐廳完全不想凸顯自己，而是接受自己在視覺上只是大梅港整體的一小部分。建築明顯更有未來感，玻璃和鋼材用得更多，稜角也比維瑞迪亞一般的建築更銳利。

格拉迪亞斯照著手錶上的指示繼續往前走。五分鐘後，他來到一個隧道入口，往下走，途中短暫穿過一處人潮洶湧的地方。

才剛穿過人群，他的手錶就震動了。

兩個問題，格拉迪亞斯心想。

第一，人太多，通風和過濾都不夠。格拉迪亞斯拉了一下隱私袍前方臉罩上的束帶，把鼻子以上和以下隔開。

第二，不知道那些未認證的裝置是什麼。現在幾乎每台裝置都有認證，用零知識證明確認它出自某家製造商的某個批次。五十五台裡有六台未認證，比例異常地高。可惜沒時間弄清楚。格拉迪亞斯想，可能是哪個孩子的科學作業，也可能在大梅港有沒認證的裝置本來就很正常——畢竟從維瑞迪亞的角度來看，這整塊地都只是一家巨型企業的私有財產——也可能是隱藏的間諜攝影機，或更糟的東西。他稍微加快腳步，繼續往前走。

在迷宮般的通道裡又轉了好幾個彎之後，他再次來到戶外，這次是在一座隱密庭院的正中央。這裡擺了幾張桌椅，有人在吃東西、喝水。格拉迪亞斯找到一張位在包廂裡的桌子，包廂外有一道布簾擋著。他走進去坐下。

桌子靠裡那一端的正中央有一盞裝飾燈，兩側各有一朵大花。包廂角落的地板上，格拉迪亞斯注意到靠牆放著一個白色盒子。他湊過去細看，手錶就震動了。PM2.5 的讀數低於 1。一定是空氣清淨機，他想。他把隱私袍的兜帽拿下來。

他用手錶碰了一下桌子中央的綠色圓圈，片刻後聽見一聲確認音。

兩分鐘後，一台有笑臉的機器人滑到桌邊，送來水和一份沙拉。格拉迪亞斯把兩樣都接過來放到桌上，機器人便滑走了。

五分鐘後，另一個穿著隱私袍的男人走了進來。

「所以，我們終於見面了。」

「你查出我是誰，說你知道一些我非聽不可、卻只肯當面講的事，又把我帶到大梅港一個我根本不知道存在的偏僻角落。到現在我連你叫什麼都不知道。」

「啊，我叫德爾瓦特。幸會。」

「我是格拉迪亞斯。」

「我知道。你太太叫賽菈，你孩子的名字是——」

「你是想恐嚇我嗎？」

「其實不是。不過現在想想，那大概比較像是在炫耀。真是失禮了。」

兩人沉默了幾分鐘，都摘下了隱私袍的臉罩和兜帽。格拉迪亞斯開始喝水、吃沙拉。德爾瓦特用自己的手錶碰了一下桌上的綠色圓圈，一分鐘後，他的茶送來了，還有某種長方形的營養棒，附一支叉子。

格拉迪亞斯又往前傾。

「所以你想要什麼？」

「你最近對掌舵制度還滿意嗎？」

「跟任何制度一樣，它有缺點，但大致上還算可以吧？」

「我懂了，看來你的心防我還沒攻破。好，就拿 Dreadknot 的演唱會來說。他們是很棒的樂團，很好玩，對吧？」

「是啊，我喜歡他們。」

「但有一群哨兵想把他們推上第四級，就因為他們的歌詞不夠溫和。」

格拉迪亞斯點頭表示同意。

「你很勇敢，投了第三級。大多數見習生都會屈從於他們以為哨兵想要的答案。你沒有。這很難得。」

「不過我們再舉個例子。你覺得大梅港怎麼樣？」

「顯然是個好地方。跟維瑞迪亞不一樣，但自有它的美和氣派。不是每個人都會喜歡，但我能理解為什麼很多人喜歡來這裡。」

「那，你知道他們的掌舵稅是多少嗎？」

「掌舵稅還好，但他們的土地稅真的被課得很重。」

「沒錯。一套深思熟慮、說明這地方對維瑞迪亞有多少好處的論證，還比不上一句幾乎沒經過思考的『我不喜歡你』。」

「那你有什麼主張？」

「自由。真正的自由。別再試圖引導每個人，讓人們真正的自我展現出來。」

「那我能幫上什麼忙？」

「如果你兩個月後獲准轉正，打算當哨兵還是守律者？」

「到目前為止想的是哨兵。」

「當守律者。然後看到任何規準，就投票刪掉。」

「就這樣？這就是你的計畫？」

「你看，現在哨兵比守律者多得多。而哨兵正是大家都想影響的對象。為什麼？因為哨兵直接連到世界上的具體事物。守律者調整的是全域的規則。但任何一條規則對任何一家企業的影響都有限，而且每條規則大概有二十個守律者在決定。當哨兵，你的影響具體得多。也比較好玩。」

「我的計畫不一樣。我想盡可能拉攏更多守律者，因為我要的是體制上的改變。重點不在一場演唱會，也不在一塊紫色用得太多的飛地。重點是把維瑞迪亞人從這種眾人偏見的暴政中解放出來，讓他們做自己。」

「你也想廢掉圖譜募資嗎？」

「我覺得圖譜募資在很多方面確實也管太多了，但我的重點是掌舵。」

「圖譜募資資助的很多開放科技，對哲戈現代化、保衛自己一直很關鍵，你不覺得這很重要嗎？」

「聽著，我喜歡他們的人民，但我們真的是在玩一場危險的遊戲，都快變成在資助一場可能的戰爭了。我們應該先處理自己的問題。」

德爾瓦特不再說話，開始喝茶、吃營養棒。格拉迪亞斯趁這個空檔思考德爾瓦特的話，一邊繼續喝水，把沙拉吃完。

「掌舵根本就是在過度操縱人心——這個想法很有意思。我不確定自己是否完全同意直接把一切歸零，尤其是砍掉圖譜募資——如果掌舵稅歸零，我們就非砍不可。」

格拉迪亞斯停了幾拍，看著德爾瓦特。德爾瓦特也看著他。兩人各自又啜了一口飲料。

「不過好吧，就算有些部分我可能同意，我為什麼要聽你的？」

「嗯，我認識你，我知道你住哪，我知道你怎麼想。如果連我都查得出這些，想像一下藍鯨能做到什麼地步。或者說，北極人。我可以幫忙保護你。但我也需要你的幫忙。」

「總之，你提交最終路線選擇的期限大約在一個月後。別選哨兵，當守律者。我們就先從這一步開始。」

德爾瓦特站起來，走出包廂。

格拉迪亞斯讓布簾中間的縫微微敞開，看著德爾瓦特離開。就在德爾瓦特快要消失在視線之外時，另一個穿著隱私袍的人從隔壁包廂走出來，跟在德爾瓦特後面。

格拉迪亞斯看了一眼手錶。
